# Sanity Schema Types Guide

Follow the [Studio excellence course](https://www.sanity.io/learn/course/studio-excellence) as a guide on schema development

## Checklist

- [ ] Only use references when content will be reused, otherwise prefer using objects to embed a type in a document
- [ ] Grouped fields
- [ ] Descriptions
- [ ] Icons
- [ ] Predefined options for radio/select inputs
- [ ] Default values where appropriate
  - [ ] Generate slugs from titles
- [ ] Validation
  - [ ] Required fields
  - [ ] Validation rules
  - [ ] Error messages
- [ ] Document list previews
